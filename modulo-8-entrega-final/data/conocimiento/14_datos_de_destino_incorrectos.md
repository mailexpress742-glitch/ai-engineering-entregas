# Datos de destino incorrectos

## Corrección de domicilio
Un cambio de domicilio o de código postal se acepta solo antes de la primera visita del distribuidor, y se pide a Distribución. Una vez iniciada la distribución la pieza no puede redirigirse: se espera el resultado de las visitas.

## Dirección inexistente
Si el distribuidor registra "dirección inexistente", la pieza no se visita por segunda vez y pasa directamente a devolución al remitente. El cliente debe reimponer con el domicilio correcto.

## Cartas documento
Una carta documento con domicilio incorrecto no puede corregirse: requiere una nueva imposición, con costo, salvo que el error haya sido de MailEx al cargar los datos.

## Error de carga de MailEx
Si el error es de carga interna (por ejemplo, un código postal mal cargado), se corrige sin cargo y se reimpone con prioridad. Se escala a Distribución con prioridad media.

## Qué decir al cliente
Se informa que el domicilio no se puede modificar una vez iniciada la distribución y se indican las opciones: esperar el resultado, o reimponer con el domicilio correcto.
